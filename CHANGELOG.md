# Changelog

## 0.1.0

- First standalone release of `QuantumQueryComplexity`, extracted from
  `troyjlee/tcs-formalizations` at `6cb3955276c61ef96bd1011fd8321ce17db699a0`.
- Preserves the production Lean modules and their import paths, including
  the `2^14` value-query and `2^15` XOR-query characterization upper bounds.
- Adds installation documentation, compiled usage examples, and a separate
  downstream-project check.
- Includes the seven-claim Palomar foundations package and paper correspondence.
- Requires Lean and Mathlib 4.35.0-rc2; exact dependencies are in the manifest.
